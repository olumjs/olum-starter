What state holds

{state.note}

The rule: whatever the user types must land back in state, because the template is the source of truth on every re-render. When state and the live content already agree the patcher writes nothing, so the caret never jumps. Leave a contenteditable out of state and the next re-render will wipe it.

Keep the interpolation tight against the opening and closing tag, on one line: any newline you leave between them becomes real whitespace inside the editable text.
